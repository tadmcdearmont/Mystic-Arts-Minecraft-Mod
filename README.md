# Mystic Arts Mod (Fabric 1.20.1)

A modernization and remake of RWTema's famous **The Monk Mod** for **Minecraft Java 1.20.1 Fabric**.

## Download Public Releases
You can download the compiled mod JAR directly from:
👉 **[Latest GitHub Release](https://github.com/tadmcdearmont/Mystic-Arts-Minecraft-Mod/releases/latest)**

Download `mysticarts-1.0.0.jar` and drop it into your `.minecraft/mods` folder along with Fabric API.

## Building via GitHub Actions (Cloud Build)
Whenever new commits are made to `main`, GitHub Actions automatically:
1. Sets up JDK 17 (Temurin).
2. Runs `./gradlew build`.
3. Creates a new Release on [GitHub Releases](https://github.com/tadmcdearmont/Mystic-Arts-Minecraft-Mod/releases) with the attached `mysticarts-1.0.0.jar`.

## In-Game Quickstart
1. Craft the **Mystic Codex** using: 1 Book + 2 Lapis Lazuli + 1 Leather.
2. Remove all armor and empty your hands to honor the **Ascetic Vow**.
3. Punch 10 wooden logs with your bare fists to unlock **Level 1: Fist of Oak**!
